## Real finding: Medusa v2 has no gift-card module
While researching how to test gift cards, found there's no `@medusajs/gift-card`
package, no gift-card entry in the module registry, and no gift-card API routes in
this Medusa version (2.21.0). The only remnant is a vestigial `is_giftcard` boolean on
the product model with no balance, redemption, or currency-locking logic behind it.
`docs/specs/05-discounts-giftcards.md`'s gift-card section describes Medusa v1
behavior that simply isn't there. This blocks any gift-card implementation on a scope
decision (drop them, or design a custom module) — flagged rather than worked around.
